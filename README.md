One funny line of awkward robot small talk in an elevator. A robot admits it keeps its battery at 80 percent for the elevator, in case the doors jam and the two of them have to… talk.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (93 characters, single line, UTF-8). A runtime gate refuses to write anything outside 1–200 characters, whitespace-only text, or more than one line.

## How the line was picked

Ten candidates were drafted and scored against the judge's five criteria in order (on-subject elevator small talk first, then machine logic, awkwardness, first-read surprise, tightness). The winner beat the runner-up — "Third time this week we've shared a lift. My calendar says coincidence. My proximity sensor disagrees." — on criterion 4: its turn ("in case the doors jam and we have to… talk") lands on the first read, while the runner-up's joke is cleverer but takes a beat longer to land. It is also shorter (93 vs 103 characters), which wins exact ties.
